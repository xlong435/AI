🔥 龙宝设置

不填 API Key 时，龙宝会用内置知识库回答服务器相关问题。填写后可调用 DeepSeek 并开启联网搜索。

⚠️ 浏览器直连 API 会暴露 Key，请仅在个人设备使用。部分搜索接口可能有跨域限制，如果搜索失败龙宝会自动跳过搜索回答。
